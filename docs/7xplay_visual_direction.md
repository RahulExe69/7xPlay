# 7xPlay Visual Identity — implementation notes

The committed product artwork is the visual source of truth:

- Product launcher artwork: `products/7xplay/assets/icon.png`
- Full product wordmark: `products/7xplay/assets/wordmark.png`

The visible identity is a near-black cinematic background, gold/yellow and orange-red for the 7/play symbol, and hot pink through violet for the X. UI accents use that warm neon family; cyan and teal are not 7xPlay's primary product colours.

The token JSON in the brand hub is explicitly marked draft/directional. Do not let its preliminary values override the committed icon and wordmark. Keep gradients restrained in the interface: the artwork itself already carries the full glow and colour energy. Use gold/orange for primary actions, pink/violet sparingly for secondary emphasis, and near-black/purple-black surfaces for depth.

Asset usage:
- `icon.png` is for the Android app launcher only.
- `wordmark.png` is for in-app brand placement, including the Home header.
- Do not use launcher artwork as a generic in-app logo.
- Do not use the current draft blue-green adaptive layers as replacements for the product icon.
